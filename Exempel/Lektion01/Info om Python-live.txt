Python: Ett programmeringsspråk

Ett programmeringsspråk är ett språk som datorer förstår.

Python är ett programmeringsspråk som är relativt lätt att lära sig; koden är mer
	lättläslig än i många andra programmeringsspråk. Grammatiken är i princip
	engelska meningar.


Exempel på hur kod kan se enklare ut när man använder Python:

for i in range(len(food)):
	print(food[i])

eller

for piece in food:
	print(piece)


Python är ett objektorienterat programmeringsspråk.
	Denna term kommer att vara viktig senare i kursen men vi börjar prata om vad
	det betyder redan nästa lektion.

Pseudokod, låtsaskod:
	Kodliknande text som man använder för att "skissa" program eller förklara
		koncept.
