Python: Ett programmeringsspråk

Ett programmeringsspråk är ett språk som datorer förstår.

Python är ett programmeringsspråk som relativt lätt att lära sig;
	koden är mer lättläslig än i många äldre programmeringsspråk.
	Grammatiken är i princip engelska meningar.


Exempel på hur kod kan se enklare ut när man använder Python:

for i in range(len(food)):
	print(food[i])

eller

for piece in food:
	print(piece)


Python är ett objektorienterat programmeringsspråk.
	Denna term kommer att vara viktig senare i kursen men vi börjar redan
	nästa lektion med att prata om vad det betyder.


Var används Python:

	Webbutveckling
	Dataanalys
	Maskininlärning
	AI
	Scripting

Ett urval av företag och organisationer som använder Python:
	Google, Spotify, Netflix, Facebook, Dropbox, Reddit, SAS, ICA, NASA


Syntax:
	Hur man skriver saker. I naturliga språk kallar vi det för gramatik.
	Jag kommer att tjata jättemycket om syntax.


Psedudokod, låtsaskod:
	Kodliknande text som man använder för att "skissa" program eller förklara
		koncept.
		
	För varje sak i listan food:
		Skriv ut den saken på skärmen
